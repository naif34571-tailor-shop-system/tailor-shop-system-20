# مشغل الخياطة — نظام الإدارة الشامل

مشروع Vite + React جاهز للنشر للحصول على رابط عام دائم يفتح البرنامج من أي مكان.

## أسرع طريقة (بدون سطر أوامر) — عبر Vercel

1. أنشئ حساب مجاني على https://vercel.com (تقدر تسجل دخول مباشرة بحساب GitHub).
2. اضغط **Add New → Project**.
3. اختر **Deploy without Git** / أو اسحب هذا المجلد بالكامل إلى الصفحة (Drag & Drop).
4. Vercel يكتشف أنه مشروع Vite تلقائيًا وينفذ `npm install` و`npm run build` بنفسه.
5. بعد دقيقة أو اثنتين يعطيك رابط دائم مثل:
   `https://tailor-shop-system.vercel.app`
   هذا الرابط يفتح من أي جهاز وأي مكان.

## أو عبر سطر الأوامر (Vercel CLI)

```bash
npm install -g vercel
cd tailor-shop-app
npm install
vercel --prod
```

سيسألك عن اسم المشروع ثم يعطيك الرابط مباشرة.

## أو عبر Netlify (بديل)

```bash
npm install
npm run build
```

ثم اسحب مجلد `dist` الناتج إلى https://app.netlify.com/drop — يعطيك رابطًا فوريًا.

## التشغيل محليًا للتجربة قبل النشر

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`

## ملاحظة مهمة عن حفظ البيانات

هذه النسخة تحفظ البيانات داخل متصفح كل جهاز (localStorage) بدل نظام تخزين Claude،
لذلك كل جهاز/متصفح يفتح الرابط سيكون له نسخة بيانات منفصلة (تحفظ نفسها تلقائيًا).
لو تبي قاعدة بيانات مركزية يشتغل عليها كل الفروع والموظفين بنفس الوقت من أي جهاز،
هذي هي الخطوة التالية المنطقية بعد النشر، وتحتاج ربط قاعدة بيانات حقيقية
(مثل Supabase أو Firebase) بدل التخزين المحلي — أقدر أجهزها لك إذا حبيت.
